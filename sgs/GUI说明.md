# 三国杀 1v1 胜率模拟器 — GUI 使用说明

> 运行：`python gui.py`　（Windows 11，需 Python 3.14 + Tkinter 8.6）
>
> 界面为三页签：**设置** / **胜率结果** / **单局回放**。所有参数调整后**立即生效**，
> 关闭窗口时自动保存到 `gui_settings.json`，下次启动自动恢复。

---

## 一、界面总览

窗口大小 1200×780（最小 1000×640）。三个页签：

| 页签 | 作用 |
|---|---|
| **设置** | 调规则/AI 参数（滑块/下拉/勾选）、勾选双方技能、启动批量模拟 |
| **胜率结果** | 显示上一批模拟的胜率条、伤害/手牌、技能触发、回合分布图表 |
| **单局回放** | 逐行播放单局日志（播放/暂停/单步/调速），可复现任意种子 |

所有批量模拟统一走 `simulator.run_batch`，单局走 `run_single`，GUI 与命令行
（`python main.py -n 2000 -w 8 -s 42`）同源，结果一致。

## 二、页签一：设置

### 2.1 顶部运行参数

| 参数 | 含义 | 说明 |
|---|---|---|
| **对局数** | 每批模拟多少局 | 10–50000，越多越稳定、越慢 |
| **并行进程数** | 同时跑的进程数 | 1 = 单进程（最稳定）；多进程更快 |
| **种子偏移** | 随机数种子 = 偏移 + 局序号 | 固定值可**复现**结果 |

### 2.2 操作按钮

| 按钮 | 作用 |
|---|---|
| **开始模拟** | 后台跑一批对局，完成后自动切到结果页显示 |
| **停止** | 请求停止。注意：multiprocessing 无法优雅中断，当前批会**跑完才结束** |
| **恢复默认** | 把全部控件恢复到 config.py 里的默认值 |
| **保存配置…** | 把当前界面设置导出为 JSON 文件 |
| **载入配置…** | 从 JSON 文件恢复界面设置 |

### 2.3 参数区（中部可滚动）

按 `ui_spec.py` 自动生成，每个参数一行：**标签 + 控件 + 灰色说明**。
控件类型：
- **勾选框** —— 布尔开关
- **下拉框** —— 枚举选择
- **数字框** —— 整数（Spinbox）
- **滑块 + 数值** —— 小数连续调节
- **文本框** —— 武将名等文字

#### ① 武将与规则
| 参数 | 说明 |
|---|---|
| A/B 武将名 | 仅显示用（结果图表、回放日志中展示的名字） |
| A/B 体力上限 | 1–12，影响生存、节命/据守等 |
| A/B 势力 | 影响庸肆摸牌数、救援 |
| A/B 性别 | 影响雌雄双股剑 |
| 主公设定 | 无主公 / A 主公 / B 主公；影响救援、激将、伪帝 |
| 牌堆 | 标准版 / 标准+军争（军争含酒、火攻、火杀雷杀、藤甲等） |
| 摸牌叠加规则 | 突袭取代全部摸牌 / 可叠加（非官方） |
| 先手 | 随机 / A 先手 / B 先手 |
| 开局手牌数 | 0–10 |
| 观星张数 | 0=官方规则（存活数≤5）；正数=固定看 N 张（调强观星） |
| 庸肆张数 | 0=官方（势力数，1v1=2）；正数=固定 N 张（摸牌额外 N/弃牌至少 N） |
| 超时回合数 | 超过判定平局/超时胜者 |
| 武器技能生效 / 防具技能生效 | 连弩、寒冰、八卦阵等开关 |

#### ② AI·通用
| 参数 | 说明 |
|---|---|
| 永远出闪 | 关掉后 AI 可"卖血换节命/不屈" |
| 受伤就用桃回复 | 关掉后 AI 会存桃（配合心战卖血流） |
| 毅重不装防具 | 毅重（无防具时黑杀无效）角色不装任何防具 |

#### ③ AI·A 专属
| 参数 | 说明 |
|---|---|
| 突袭 | 期望价值 / 总是发动 / 从不发动 |
| 好施 | 从不 / 总是 / 期望价值（手牌≤3 才用，避免资敌） |
| 制衡价值阈值 | 价值低于该值的牌弃掉重摸 |
| 制衡最少弃牌 | 至少弃几张才发动制衡 |
| 出杀命中阈值 | 调低=更敢出杀 |
| 驱虎 | 仅节命连招 / 从不 / 总是 |
| 驱虎手牌上限 / 体力差 | 节命连招的条件 |
| 仁德触发体力 / 最少送牌 / 最多送牌 / 送牌惩罚 | 仁德回血策略参数 |
| 观星保留阈值 | 观星把价值高于该值的牌放牌堆顶 |
| 重视兵粮寸断 | A 把兵粮视为高价值断粮牌：优先打出、不弃不制衡 |

#### ④ AI·B 专属
| 参数 | 说明 |
|---|---|
| 克己出杀阈值 | 手牌杀超过该张数才主动出杀（囤牌流） |
| 克己可斩杀即出手 | 能斩杀时无视囤牌直接出手 |
| 据守触发体力 / 对手手牌 / 手牌>体力时用 | 据守使用条件 |
| 心战 | 手牌>体力时 / 从不 |
| 心战卖血流 | B 存桃不治伤、故意吃伤害（不闪/不应南蛮）保证心战发动 |
| 决斗触发阈值 | 估计对手杀≤该值才用决斗 |
| 囤死兵粮寸断 | B 绝不使用兵粮，囤死留手牌喂心战 |

#### ⑤ AI·卡牌与细节
| 参数 | 说明 |
|---|---|
| 使用南蛮入侵 / 万箭齐发 / 五谷丰登 | 各锦囊是否使用 |
| 先喝酒再出杀 | 酒杀连招 |
| 杀价值系数 | 杀的价值 = 命中×伤害×该系数 |
| 最小动作价值 | 价值低于该值的出牌动作不执行 |
| 寒冰剑猎手 / 削牌 / 蓄爆流 | 实验功能（实测多为负收益） |
| 安全伤害模式 | A 主打南蛮/决斗/火攻，不出杀/万箭（专克雷击） |

> **死参数**（改了不生效，已从界面剔除）：`card_value_scale`、`use_taoyuan_when_hp_le`。

### 2.4 武将技能区

A/B 两栏，各列出 **26 个已实现技能**的勾选框，**勾选即生效**。
- A 默认勾选：突袭、驱虎、节命、制衡、救援、好施、缔盟、仁德、激将、观星、空城、庸肆、伪帝、闭月
- B 默认勾选：不屈、义从、克己、心战、挥泪、据守、毅重、狂骨、谦逊、连营
- **可选（默认不勾）**：雷击、鬼道（张角技能组）

> **雷击提示**：雷击需持技能方**打出闪**才触发。A 默认"安全伤害模式"不开杀/万箭，
> 因此 B 勾选雷击后可能几乎不触发——要测雷击对局，请先把"安全伤害模式"关掉。
> 另注意主公技（救援/激将）需设置主公才生效；缔盟在 1v1 中不可用。

## 三、页签二：胜率结果

点击「开始模拟」后自动显示：

1. **汇总文字**：总局数、A/B 胜率、平局率
2. **统计文字**：平均回合、双方平均手牌、双方总伤害
3. **胜率分布**：横向堆叠条（A 红 / B 蓝 / 平局灰）
4. **伤害与手牌对比**：双方总伤害、平均手牌横条
5. **技能触发次数**：本批触发最多的 12 个技能（按 A/B 上色）
6. **回合数分布**：直方图，横轴回合数区间、纵轴局数

## 四、页签三：单局回放

### 4.1 操作

| 控件 | 作用 |
|---|---|
| **种子** | 指定要复现的对局（种子 = 该值） |
| **开始单局** | 后台跑一局并载入日志（当前设置生效） |
| **▶ 播放 / ⏸ 暂停** | 播放/暂停逐行显示 |
| **单步** | 一次显示一行（暂停时可用） |
| **复位** | 回到第一行、清空日志 |
| **速度滑块** | 每行间隔毫秒数（20–800，越小越快） |

### 4.2 日志阅读

- **回合行**（`===== 第 N 回合 …`）以橙色加粗显示，状态栏同步显示当前回合双方 hp/手牌。
- 每行记录一个事件：摸牌、使用/打出、判定、伤害（带原因）、技能发动等。
- 结局行以绿色加粗显示（如"死亡！击杀者"）。
- **不会自动滚到底部**：新一局从顶部开始看，播放中新行从下方追加，可自由滚动回看。
- 支持鼠标滚轮；长行用底部**横向滚动条**查看。

### 4.3 复现对局

在"设置"页调好参数 → 记下"种子偏移" → 回放页输入一个种子 → 开始单局，
即可复现该参数下该种子的完整一局。

## 五、配置持久化

- 关闭窗口时自动保存全部设置到项目目录下的 **`gui_settings.json`**（已 gitignore）。
- 启动时自动恢复；文件缺失则用 config.py 默认值。
- 新版本新增的参数若不在旧配置文件里，会**自动用默认值**（不影响已保存的参数）。

## 六、常见问题

| 问题 | 说明 |
|---|---|
| 改了参数但结果没变 | 运行中的 GUI 是旧代码，改完 `.py` 后**重启 GUI** 才生效 |
| 点了停止还在跑 | multiprocessing 无法中断当前批，会跑完才停 |
| 雷击/鬼道勾了却不触发 | 雷击需打闪；A 的安全伤害模式会避开杀/万箭，先关掉它 |
| 想调出一个平衡的对局 | 参考 `TODO.md`：庸肆张数是最强杠杆（4→A≈90%，3→~85%，2→更低） |
